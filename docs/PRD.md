# 노션 견적서 웹 뷰어 & PDF 다운로드 MVP PRD

## 🎯 핵심 정보

**목적**: 노션에서 작성한 견적서를 클라이언트가 보기 좋은 웹 화면으로 확인하고 PDF로 바로 받을 수 있게 한다.

**사용자**: 노션으로 견적서를 작성해 클라이언트에게 전달하는 프리랜서와 소규모 에이전시, 그리고 그 견적서를 받아보는 클라이언트.

---

## 🚶 사용자 여정

```
[견적서 작성자]
로그인/회원가입 ──(인증 성공)──▶ 견적서 목록 ──(견적서 선택)──▶ 견적서 상세
     ▲                              │  │                          │  │
     │                              │  └─(상태 필터, 새로고침)─┘   │  └─ PDF 다운로드
     └────────(로그아웃)────────────┘                              └─ 공유 링크 복사

[클라이언트]
공유 링크 수신 ──(로그인 없이 접속)──▶ 견적서 상세 ──▶ PDF 다운로드

[분기 조건]
- 비로그인 상태로 견적서 목록 접근 → 로그인/회원가입으로 이동
- 로그인 상태로 로그인/회원가입 접근 → 견적서 목록으로 이동
- 노션 조회 실패 또는 존재하지 않는 견적서 → 상세 페이지 내 오류 안내 후 견적서 목록 이동 버튼 제공
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|---------------|-------------|
| **F001** | Notion API 연동 | 노션 데이터베이스의 견적서 항목을 서버에서 조회해 목록 데이터로 변환 | 모든 데이터의 원천 | 견적서 목록 |
| **F002** | 견적서 웹 뷰어 | 헤더, 클라이언트 정보, 항목 테이블, 합계, 조건을 견적서 레이아웃으로 표시 | 핵심 가치인 보기 좋은 화면 | 견적서 상세 |
| **F003** | PDF 다운로드 | 웹 뷰어와 동일한 형식의 PDF를 한 번의 클릭으로 생성해 저장 | 핵심 가치인 문서 전달 | 견적서 상세 |
| **F004** | 견적서 목록 조회 | 견적번호, 클라이언트명, 금액, 상태, 발행일을 테이블로 표시하고 상세 링크 제공 | 견적서 진입점 | 견적서 목록 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|---------------|-------------|
| **F005** | 상태 필터 | 작성중, 발송됨, 승인됨, 거절됨 상태로 목록 필터링 | 견적서가 늘어났을 때 탐색 | 견적서 목록 |
| **F006** | 반응형 견적서 표시 | 모바일, 태블릿, 데스크톱에서 레이아웃 전환 (모바일은 항목 테이블을 카드형으로 표시) | 클라이언트 열람 환경이 다양함 | 견적서 상세 |
| **F007** | 이메일 인증 | Supabase 이메일/비밀번호 회원가입 및 로그인 | 작성자 전용 목록 보호 | 로그인/회원가입 |
| **F008** | 로그아웃 | 세션 종료 후 로그인 화면으로 이동 | 인증의 기본 쌍 | 견적서 목록 |
| **F009** | 공유 링크 복사 | 로그인 없이 열람 가능한 견적서 링크를 클립보드에 복사 | 클라이언트 전달 수단 | 견적서 상세 |
| **F010** | 목록 새로고침 | 노션의 최신 데이터를 다시 불러와 목록에 반영 | 노션 수정 내용의 실시간 확인 | 견적서 목록 |

## ✅ 정합성 검증 결과

### 1단계: 기능 명세 검증
- ✅ F001~F010 모두 페이지별 상세 기능에 존재
  - 로그인/회원가입: F007
  - 견적서 목록: F001, F004, F005, F008, F010
  - 견적서 상세: F002, F003, F006, F009
- ✅ 관련 페이지 3개(로그인/회원가입, 견적서 목록, 견적서 상세)가 모두 실제로 존재

### 2단계: 메뉴 구조 검증
- ✅ 메뉴 항목(로그인, 로고, 견적서 목록, 로그아웃)이 모두 페이지에 존재하고 기능 ID와 매핑됨 (F007, F004, F008)
- ✅ 메뉴에서 참조하는 모든 기능 ID가 기능 명세에 정의됨

### 3단계: 페이지 역참조 검증
- ✅ 페이지별 기능 ID가 모두 기능 명세에 정의됨
- ✅ 모든 페이지가 메뉴나 링크로 접근 가능 (견적서 상세는 목록 행 클릭과 공유 링크로 진입)

### 4단계: 누락/고아 항목 검증
- ✅ 명세에만 있는 기능 없음
- ✅ 페이지에만 있는 기능 없음
- ✅ 메뉴에만 있는 항목 없음
- ✅ 각 기능 ID는 정확히 한 페이지에만 배정됨 (중복 없음)

### 설계 결정 사항

- **F001 (Notion 연동)**: 조회 시작점인 견적서 목록에 배정했다. 견적서 상세의 단건 조회는 F002에 포함된다.
- **F004 → F005 분리**: 원본 F004의 "상태 필터" 기능을 F005로 분리했다.
- **추가 기능**: 요청에 있던 반응형 지원(F006), 인증(F007, F008), 공유(F009), 새로고침(F010)을 MVP 지원 기능으로 추가했다.
